adapter and a separate GitHub state branch. A create-only claim is followed by
an independent armed acknowledgement before the sole POST. Both processes cache
the cleanup identity. A lost create reply is never retried, and an early empty

the already rehearsed separate mutually authenticated TLS port. The new entry
requires exactly one provider mapping for each of TCP22/TCP8443, with a matching
direct SSH address and distinct public ports. File delivery is pinned SSH;
model requests additionally require the pinned TLS certificate/client key.
